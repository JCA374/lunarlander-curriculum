# Lunar Lander curriculum: wind, turbulence and an obstacle

A CMA-ES-trained lander that should land between the flags in Gymnasium's LunarLander with strong gusty wind, turbulence and one more obstacle, learned
through a staged curriculum. The plan is in [PLAN.md](PLAN.md), and the working method in [METHOD.md](METHOD.md).

Earlier projects: [lunarlander-neat-wind](https://github.com/JCA374/lunarlander-neat-wind) (NEAT, best 91% landed in wind),
[bipedal-cmaes](https://github.com/JCA374/bipedal-cmaes) (where the method was developed).
