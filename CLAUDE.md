# lunarlander-curriculum

- Start with PLAN.md (the goal, curriculum, lessons, first steps) and METHOD.md (how to run the work: 2-hour check-ins,
  one change at a time, verification on fresh flights, the log page, the podcast).
- Podcast: use the `project-podcast` skill (settings in `podcast.conf`). Make an episode for every major event.
- Background jobs: `setsid nohup`. SIGTERM must checkpoint. Never `pkill -f` a pattern that's also in your own command line.
- Never claim a result that wasn't measured on fresh seeds (≥ 100 flights, or 1,000 for the final goal).
